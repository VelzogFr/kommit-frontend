# Stack technique

## Frontend

- **Langage** : TypeScript (v6)
- **Framework** : React
- **Build** : Vite
- **Styling** : Tailwind, shadcn/ui (avec Base UI)
- **Routing** : React Router
- **Données** : TanStack Query
- **Validation** : Zod
- **Tests** : Vitest, React Testing Library, Playwright

## Infra

- **Hébergement front** : Vercel
- **Hébergement back** : Render
- **Versionnement et CI/CD** : GitHub, GitHub Actions
- **Suivi** : Notion
